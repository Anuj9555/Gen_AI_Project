# WanderAI Frontend Client

Production React + TypeScript + Vite travel itinerary planner web client.

## Technologies Used
- **React 18** with **TypeScript**
- **Vite** for fast, optimized bundling
- **Tailwind CSS** for responsive SaaS styling
- **React Router 6** for route management
- **Zustand** for centralized state management
- **React Hook Form + Zod** for schema validation
- **Recharts** for budget distribution visualization
- **Leaflet & React-Leaflet** for interactive OpenStreetMap maps
- **Lucide React** for icons
- **Axios** for authenticated HTTP API requests

## Quickstart

```bash
npm install
npm run dev
```

The application will start at [http://localhost:3000](http://localhost:3000).

To build for production:
```bash
npm run build
```
